# Batch 15 — Monitoring Dashboard Live Control UI
## System
Meat Lovers CIMS powered by YohPal
## Purpose
This batch gives the owner and management a live control dashboard for daily restaurant operations.
## Monitoring Cards
The owner dashboard shows:
1. Today sales


2. Today orders
3. Paid orders
4. Low stock count
5. Pending approvals
6. Pending M-Pesa
7. Unsold food count
8. Kitchen queue count
9. Bar low-stock count
10. Cashier settlement count
## Alert Pages
### Low Stock Alerts
Shows products where current quantity is at or below reorder level.
### Pending Approvals
Shows approval requests for:
- cancellation
- discount
- stock adjustment
- refund
### Pending M-Pesa
Shows payments marked as pending M-Pesa.
### Unsold Food Alerts
Shows cooked food declared unsold today.
## Refresh Rule
Monitoring pages refresh every 15 seconds.
## Control Purpose
This dashboard helps management detect:
- poor sales
- unpaid orders
- low stock
- pending approvals
- M-Pesa delays
- cooked food wastage
- kitchen backlog
- bar shortages
- cashier settlement activity
